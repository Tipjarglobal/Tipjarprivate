### Ist Launch ausreichend?
Für FastAPI + MongoDB + React App mit Tesseract OCR, Pillow-Bildverarbeitung, ~40MB Bild-Assets und Background-Loops könnte Launch knapp werden:
- Tesseract OCR speicherintensiv, besonders bei Bildverarbeitung
- Pillow + große Bilddateien können Memory-Spitzen verursachen
- Background-Loops verbrauchen zusätzlichen Speicher
- Wenn App beim Start viele Libraries lädt oder Daten cached, kann 2GB Grenze überschreiten

Anzeichen dass mehr Speicher braucht:
- App startet neu ohne Grund
- 502 oder 520 Fehler von Cloudflare
- In Logs "OOMKilled" (Out Of Memory)
- Pod-Status "CrashLoopBackOff"

2. Gehe zum Resources-Tab
3. Klick auf "Upgrade"

   - Elite: 8Gi-16Gi (16 GB) - 1100 Credits/Monat
